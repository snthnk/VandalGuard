# VandalGuard: Интеллектуальный контроль и защита имущества в реальном времени

`VandalGuard` — это готовое решение на стыке искусственного интеллекта и компьютерного зрения для автоматического обнаружения актов вандализма. Система в реальном времени анализирует видеопоток с камер наблюдения и мгновенно отправляет оповещения с фотофиксацией инцидента в Telegram.

---

## Бизнес-ценность и целевая аудитория

Вандализм в лифтах, подъездах и на коммерческих объектах — постоянный источник непредвиденных расходов. Замена испорченных зеркал, кнопок панели управления, покраска стен и ремонт камер обходятся ТСЖ, управляющим компаниям (УК) и владельцам бизнеса в значительные суммы ежегодно.

**VandalGuard решает эти проблемы для:**
*   **Управляющих компаний (УК) и ТСЖ:** Защита лифтовых кабин и подъездов, мгновенное информирование диспетчеров или консьержей.
*   **Собственников коммерческой недвижимости:** Мониторинг входных зон, коридоров и зон самообслуживания.
*   **Интеграторов систем безопасности:** Простое расширение функционала существующих систем видеонаблюдения умными ИИ-оповещениями.

---

## Ключевые возможности

*   **Классификация на базе ИИ (YOLO):** Анализ изображения на уровне кадра (классификация всего кадра как `vandalism` / `nonVandalism`), что снижает требования к вычислительным ресурсам по сравнению с трекингом объектов.
*   **Асинхронная архитектура (Asyncio):** Параллельная обработка видеозахвата, классификации кадров и работы Telegram-бота без задержек.
*   **Буферизация с защитой от отставания:** Встроенная очередь фиксированного размера (`QUEUE_SIZE`) автоматически сбрасывает устаревшие кадры, гарантируя обработку только актуального видеопотока.
*   **Интеллектуальный спам-фильтр (Cooldown):** Настраиваемый интервал блокировки повторных оповещений (`COOLDOWN_MINUTES`) предотвращает засорение чата уведомлениями по одному инциденту.
*   **Оповещения в Telegram (aiogram 3.x):** Отправка детального текстового предупреждения с JPEG-снимком инцидента, а также автоматический текстовый fallback в случае сбоев кодирования изображения.
*   **Безопасное завершение работы (Graceful Shutdown):** Корректный перехват системных сигналов `SIGINT` и `SIGTERM` для освобождения видеоканала, завершения фоновых задач и закрытия сессий бота без утечек памяти.

## Архитектура системы

### Краткое описание компонентов:
1.  **Захват видеопотока:** OpenCV считывает кадры из указанного источника. Для снижения нагрузки обрабатывается только каждый N-й кадр (`SKIP_FRAMES`).
2.  **Очередь кадров:** Очередь имеет жесткий лимит размера. Если воркер занят анализом, а очередь заполняется, старые кадры отбрасываются для исключения задержек оповещения.
3.  **ИИ-анализ:** Воркер отправляет кадр в модель YOLO, которая возвращает вероятности классов через `result.probs`. Если класс `vandalism` превышает `CONFIDENCE_THRESHOLD`, событие передается дальше.
4.  **Контроль отправки:** Проверяется интервал Cooldown. Если он истек, время последнего срабатывания обновляется, и отправляется Telegram-алерт.

## Установка и запуск

### 1. Клонирование репозитория
Склонируйте исходный код с помощью Git:
```bash
git clone https://github.com/snthnk/VandalGuard.git
cd VandalGuard
```

### 2. Подготовка виртуального окружения
Создайте изолированное окружение и активируйте его:
```bash
# Для Linux / macOS:
python3 -m venv venv
source venv/bin/activate

# Для Windows:
python -m venv venv
venv\Scripts\activate
```

### 3. Установка зависимостей
Установите необходимые пакеты:
```bash
pip install -r requirements.txt
```

### 4. Загрузка весов модели
Файл весов модели `VandalGuardModel.pt` не включен в репозиторий.
Скачайте обученные веса по официальной ссылке:
👉 [**Скачать VandalGuardModel.pt**](https://drive.google.com/file/d/1RUJyJoW2O16L_v3oIAVKkhQ7CRXjhayo/view?usp=sharing)
Поместите скачанный файл в корневую папку репозитория.

## Конфигурация и примеры настройки

Система конфигурируется с помощью файла `.env` в корневом каталоге.

### Пример файла `.env`
Создайте файл `.env` в корне проекта и заполните его по следующему образцу:
```env
BOT_TOKEN=123456789:AAG_ExampleTokenHere_XXYYZZ
TARGET_CHAT_ID=-1001234567890
VIDEO_SOURCE=rtsp://admin:secretPass@111.111.1.100:554/stream1
MODEL_PATH=VandalGuardModel.pt
SKIP_FRAMES=3
COOLDOWN_MINUTES=3.0
CONFIDENCE_THRESHOLD=0.55
QUEUE_SIZE=2
LOG_LEVEL=INFO
```

### Таблица параметров конфигурации

| Переменная окружения | Тип | По умолчанию | Описание и валидация |
| :--- | :--- | :--- | :--- |
| `BOT_TOKEN` | `str` | *Обязательный* | Токен вашего Telegram-бота, полученный от `@BotFather`. |
| `TARGET_CHAT_ID` | `int` | *Обязательный* | ID чата, группы или пользователя, куда будут поступать тревоги. Должен быть целым числом. |
| `VIDEO_SOURCE` | `str`/`int` | `0` | Источник видеопотока. Поддерживает индекс камеры, RTSP URL или путь к файлу. |
| `MODEL_PATH` | `str` | `VandalGuardModel.pt` | Путь к файлу весов модели YOLO. |
| `SKIP_FRAMES` | `int` | `3` | Шаг анализа кадров. Должен быть строго положительным целым числом (> 0). |
| `COOLDOWN_MINUTES`| `float` | `3.0` | Интервал блокировки спама (в минутах). Должен быть неотрицательным числом (>= 0). |
| `CONFIDENCE_THRESHOLD`| `float`| `0.5` | Порог уверенности классификатора. Должен быть в диапазоне от `0.0` до `1.0`. |
| `QUEUE_SIZE` | `int` | `2` | Максимальный размер очереди кадров. Должен быть строго положительным целым числом (> 0). |
| `LOG_LEVEL` | `str` | `INFO` | Уровень логирования (`DEBUG`, `INFO`, `WARNING`, `ERROR`). |

### Варианты настройки `VIDEO_SOURCE`
*   **Локальная USB/веб-камера:** Укажите индекс устройства в виде числа. Например: `0` (или `1` при наличии нескольких камер).
*   **IP-камера (RTSP-поток):** Укажите полную RTSP ссылку. Пример: `rtsp://admin:password@192.168.1.50:554/h264Preview_01_main`
*   **Видеофайл (для тестов/демо):** Укажите путь к файлу. Пример: `elevator_records/demo.mp4`

Для проверки работоспособности логики детекции и конфигуратора запустите встроенные тесты:

## Технические особенности и ограничения

*   **Классификация кадров vs Детекция объектов:** Система работает по принципу **классификации кадров** (image-level classification). Она определяет вероятность присутствия вандализма на всем изображении в целом (через вероятности `result.probs`), а не выделяет вандализированные объекты рамками (bounding boxes). Это делает модель исключительно легковесной, но требует правильного ракурса камеры.
*   **Безопасность:** Файл `.env` содержит конфиденциальный токен Telegram. Никогда не фиксируйте этот файл в системе контроля версий (Git). Добавьте его в `.gitignore`.
*   **Производительность:** На слабых серверах без GPU рекомендуется увеличить значение `SKIP_FRAMES` (например, до 5 или 10), чтобы избежать отставания обработки видео.
*   **Идеи для расширения:**
    1.  *Запись видеофрагментов:* Доработка воркера для записи и отправки короткого видеоролика момента инцидента вместо одного фото.
    2.  *Интеграция с исполнительными устройствами:* Отправка сигнала на блокировку дверей лифта при обнаружении вандализма с высокой степенью уверенности.
    3.  *Мультиканальность:* Запуск нескольких параллельных асинхронных циклов захвата для одновременного анализа видео с нескольких камер.
